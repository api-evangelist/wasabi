# Wasabi

Wasabi Hot Cloud Storage is an S3-compatible object storage service offering a REST API that mirrors the Amazon S3 API for storing, retrieving, and managing objects and buckets. Wasabi provides always-consistent storage at lower cost than hyperscale providers, with no egress fees, no API request fees, and enterprise-grade performance across multiple global regions.

## APIs

- **Wasabi S3 API** — S3-compatible object storage API for buckets and objects, supporting AWS Signature V2 and V4 authentication across all Wasabi regional endpoints.
- **Wasabi Account Control Management (WACM) API** — Account management, IAM, user provisioning, access key management, and sub-account administration.
- **Wasabi Stats API** — Storage utilization analytics, bandwidth metrics, and cost reporting for FinOps and chargeback use cases.
- **Wasabi AiR API** — AI-powered media intelligence for content analysis and tagging of objects stored in Wasabi buckets.
